# RK3568 LPDDR4 开源硬件项目

本项目是一套基于 Rockchip RK3568 的 LPDDR4 硬件设计与系统资料集合，面向嵌入式 Linux、OpenWrt、边缘计算、网关及其他 ARM 应用场景。

仓库目前包含硬件原理图工程、OpenWrt 系统镜像、Rockchip 官方参考资料，以及开发过程中使用的烧录、驱动和 DDR 测试工具。项目仍在持续整理中，部分硬件参数、接口定义和使用步骤有待后续版本补充与验证。

> [!IMPORTANT]
> 当前版本适合作为开发和学习参考，尚未声明为可直接量产的最终版本。打板、焊接或烧录前，请以原理图、PCB、BOM 和实际测试结果为准，并自行完成电源、时序、信号完整性及散热检查。

## 硬件概述

本设计以 RK3568 为核心，搭配 LPDDR4 内存。RK3568 是面向嵌入式应用的 ARM SoC，集成 CPU、图形、多媒体和丰富的外设控制器。板卡实际引出的接口、内存容量、存储配置及电源方案，应以本项目原理图和后续发布的硬件规格表为准。

### 暂定硬件规格

以下表格用于开源首版说明，其中未确认的内容已明确标记，后续可按实际设计修改。

| 项目 | 当前说明 |
| --- | --- |
| 主控 | Rockchip RK3568 |
| CPU 架构 | ARM 64 位平台 |
| 内存 | LPDDR4，容量与颗粒型号待确认 |
| 启动存储 | SD 卡 |
| 电源管理 | RK809-5 |

### 设计与打板注意事项

1. LPDDR4 属于高速接口，修改布局布线后需重新检查拓扑、等长、阻抗、参考平面、过孔及串扰。
2. RK3568 的电源时序、复位、启动配置和晶振电路应按照对应版本的官方硬件设计指南复核。
3. eMMC、SPI Flash 和 DDR 颗粒应优先从 Rockchip 兼容列表中选型，并核对颗粒版本与固件支持情况。
4. 首次上电建议使用限流电源，分阶段测量各电源轨及复位、时钟信号。
5. 正式投板前应完成 ERC/DRC、封装、极性、连接器方向、阻抗叠层和可制造性检查。

## 快速开始

### 查看硬件工程

1. 安装嘉立创 EDA。
2. 打开 `hardware/ProDoc_Schematic1_2026-08-24.epro2`。
3. 检查工程字体、封装库和器件库是否完整加载。
4. 修改设计后，建议先另存新版本并在提交记录中说明改动。

### 烧录系统镜像

> [!WARNING]
> 烧录会覆盖目标存储设备中的数据。操作前务必确认设备型号、存储介质和镜像适配情况，并备份重要数据。

一般流程如下，具体按后续发布的烧录说明执行：

1. 安装 `tools/DriverAssitant_v5.13.zip` 中的 Rockchip USB 驱动。
2. 解压并启动 `tools/RKDevTool_Release_v3.19_en.zip` 中的烧录工具。
3. 使目标板进入 Loader 或 Maskrom 模式，并确认工具已识别设备。
4. 选择与硬件版本匹配的 Loader、分区镜像或完整固件。
5. 核对目标后开始烧录，完成后重启设备并查看串口启动日志。

当前仓库中的 `.img` 是否可由 RKDevTool 直接作为完整固件写入尚待确认。请勿在未核对镜像格式和分区布局的情况下盲目烧录。
